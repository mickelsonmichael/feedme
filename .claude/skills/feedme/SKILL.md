# FeedMe product reference

- [screens.md](./references/screens.md) — every screen, its file, its route, and what it is responsible for. Update it when a screen is added, removed, or changes purpose.
- [requirements.md](./references/requirements.md) — requirements grouped by screen. It is large: grep for the screen's heading or a `REQ-` id instead of reading it whole.

When behaviour changes, add or update the matching requirement: observable, testable behaviour, not implementation detail.
